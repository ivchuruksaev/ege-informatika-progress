# Тренажёр ЕГЭ по информатике

Статический сайт для занятий по проекту КИМ ЕГЭ-2027: 27 тренировочных задач с иллюстрациями по рабочей тетради, экзаменационный режим с вводом ответов и адаптивными задачами после ошибки, самооценка самостоятельности, отметка преподавателя и журнал заметок.

## Использование

- Откройте `index.html` локально или опубликуйте папку через GitHub Pages.
- Сайт не требует сервера, сборки или установки пакетов.
- Кнопка «Режим: ученица» включает/выключает заметки и отметку преподавателя.
- В режиме «Экзамен» ученица решает задания по одному без подсказок. Каждый неверный ответ добавляет две тренировочные задачи по той же теме; сессия сохраняется и её итог виден в разделе прогресса.
- Прогресс хранится в `localStorage` браузера. Для переноса нажмите «Скачать отчёт» и затем «Загрузить отчёт» на другом устройстве.
- Методика преподавателя и расширенные шаблоны программирования передаются отдельным файлом.

## Важное

Задачи в тренажёре — короткие учебные примеры по темам заданий, а не копии заданий ФИПИ. Сайт ориентирован на проект КИМ-2027, опубликованный для обсуждения 4 октября 2026 года. Перед экзаменом проверьте актуальную демоверсию на официальной [странице ФИПИ](https://fipi.ru/ege/demoversii-specifikacii-kodifikatory).
